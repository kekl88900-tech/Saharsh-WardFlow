# WardFlow — Emergency Ward Management System

**OOP Laboratory Project**  
**Developer:** Saharsh W.

## About
WardFlow is a web-based hospital ward management system that simulates patient registration, severity-based prioritization, resource allocation, emergency pre-emption, and activity logging.

## Key Features
- Patient registration and management
- Severity-based patient prioritization
- Ward resource management and assignments
- Emergency resource pre-emption simulation
- Activity logs and cloud data storage

## Key Workflow
1. Register patients and record their details.
2. Prioritize patients based on severity.
3. Manage available ward resources.
4. Assign resources to patients according to priority and availability.
5. Simulate emergency pre-emption for higher-priority cases.
6. Record allocation changes and verify saved data.

## Technologies
- HTML, CSS, JavaScript
- Supabase (PostgreSQL)
- Netlify for deployment

## OOP Concepts
The project domain can demonstrate classes, objects, encapsulation, abstraction, inheritance, and polymorphism in a Java implementation.
